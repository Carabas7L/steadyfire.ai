# Steady Fire — site statique

Site public de **Steady Fire** : page d’accueil du laboratoire H/I et espace **Science Friction**.

## Contenu du dépôt

- `index.html` — page d’accueil, avec styles intégrés ;
- `science-friction/` — accueil de Science Friction et feuille de style de lecture `read.css` ;
- `science-friction/romance/` — lecture en ligne de *La Romance de U/Sola et Igor* ;
- `science-friction/u-romanceia/` — mandat textuel U/RomanceIA V3, à utiliser avec un modèle de langage ;
- `science-friction/downloads/` — fichiers PDF et Markdown, dont l’édition tout-en-un Romance + U/RomanceIA, et fichier d’empreintes `SHA256SUMS.txt` ;
- `favicon.svg` — icône locale ;
- `.nojekyll` — publication directe sans traitement Jekyll ;
- `robots.txt` — autorisation d’indexation ;
- `INSTALLATION_PAS_A_PAS.md` — procédure GitHub Pages + Namecheap.

Le fichier `CNAME` est présent à la racine de la branche `main` et contient `steadyfire.ai`, le domaine personnalisé du site publié sur GitHub Pages.

## Propriétés de la page d’accueil

- aucune base de données ;
- aucun JavaScript ;
- aucun formulaire ;
- aucune clé ou donnée privée ;
- aucun outil d’analyse ;
- aucune ressource externe chargée par la page ;
- site adaptatif pour ordinateur et téléphone.

## Dépôt

Les sources sont conservées dans [Carabas7L/steadyfire.ai](https://github.com/Carabas7L/steadyfire.ai), sur la branche `main`, avec la page d’accueil à la racine et Science Friction dans son sous-répertoire.

La procédure complète figure dans [`INSTALLATION_PAS_A_PAS.md`](INSTALLATION_PAS_A_PAS.md).
